# 尺规 · 三维作品集

郭奥成（小郭）的三维作品集单页。纯静态，无外部依赖（不引 CDN、不引字体文件），手机/桌面都可看，离线可开。

```
https://gacn.github.io/valley-town/works/
```

## 内容结构

| 区块 | 内容 |
|---|---|
| 封面 | 左文右三图版（紫禁城 / 哈利法塔 / 宇树 R1），四个规模数字 |
| 01 作品 | 08 个项目：宫阙疑云（紫禁城白模 + 游戏）、哈利法塔、未来科技城市、金牛花园室内漫游、小郭角色《经纬》、宇树 R1、山谷小镇、小郭早点 |
| 02 尺与数 | 8 个可在工程里数出来的数字 |
| 03 做法 | 参数化 → 白模与校验 → 分区导出 → 进浏览器 |
| 04 关于 | 个人背景、工具链、联系方式 |

## 改内容

- 文案、项目、规格：直接改 `index.html` 里对应的 `<article class="work">`
- 换图：替换 `assets/<项目>/<n>.jpg`（保持文件名即可）
- 增删作品：复制一个 `<article class="work reveal">…</article>`，注意 `idx` 编号与封面统计数字（08）要一起改

## 说明

封面统计与每个项目里的数字都来自对应工程的实际数据（构件数、顶点数、高度、帧数、校验结果）。白模就是白模，未渲完就写未渲完——不做美化。

故宫白模的渲染图是低采样白模（容器无降噪），噪点明显，因此版面上按「白模 + 图纸 + 数据」呈现，而不是当成品渲染图用。
