# 山谷小镇 · Valley Town

一个能走、能开车、能进屋、能改天气的三维山谷小镇。纯前端，单页，离线可跑（three.js 已本地化，不联网）。

## 怎么打开

在有这个文件夹的机器上起一个静态服务器（手机/Termux 里也行）：

```sh
cd 山谷小镇-valley-town
python3 -m http.server 8099
```

然后浏览器打开 `http://<本机IP>:8099/`。手机同 Wi-Fi 时用手机浏览器打开电脑/手机的局域网 IP 即可。

> 直接双击 `index.html`（file://）也能跑，只是个别浏览器会限制本地资源，起 http 最稳。

## 里面有什么

- **地形**：程序生成的一条南北向河谷，两侧山脊 90–160 米，谷底滩地压平。高度函数 `VW.groundH(x,z)` 同时用于渲染和碰撞，所以脚下永远是实的。
- **河与桥**：河道带正弦摆动，水面是自定义 shader（有波纹流动）；石拱桥横跨河面，桥面有起拱，栏杆挡人。
- **12 栋可进入的房屋**：每栋有墙体、门洞、双坡屋顶、烟囱、窗（夜里亮）、室内桌/床/书架/壁炉/地毯/吊灯。墙体碰撞在本地坐标里做，门洞留了 1.7 米缺口——**12 栋全部实测能走进去**。
- **森林**：620 棵 InstancedMesh 针叶树，按坡度、海拔、离镇距离筛选，不会长在河里或广场上。
- **4 座风车**：叶片持续旋转，位置在山坡上。
- **12 位居民（行为 AI，不是固定时刻表）**：各有姓名、职业、住址、工作地点，外加**四样需求**（饿 / 累 / 想说话 / 想干爽）和**三种性格**（怕雨 / 合群 / 好奇），每人还有自己的上下班钟点、饭点、常来往的朋友。
  - 每 2–4 秒给自己打分：这会儿该干什么。候选有 干活 / 吃饭 / 躲雨 / 说话 / 串门 / 去酒馆 / 回家 / 闲逛，谁分高做谁。
  - 所以天气一变就有人跑向屋檐（怕雨的分高，不怕雨的照样抡锤）；下雨时吃饭自动改到酒馆里；下班时间错开，有人 18:10 收工有人 20:00；饭点也从 11:40 一直排到 13:40。
  - 同一个人不同天不一样：饿得慌就先去吃，不饿就直接去酒馆；合群的人下班后去朋友家串门或上酒馆，不爱热闹的回家待着。
  - 过河会自己走桥（不会涉水）；快到家时不再被自家墙挡住；卡住超过 3 秒会自己侧向挪一段再重算路线；走动时手脚摆动、身体轻微起伏。
  - 面板实时显示"此刻的居民"在干什么，靠近会说话，说的话跟当下做的事对得上。
- **汽车**：红色双门小车，油门/刹车/转向、贴地跟随坡度、桥栏杆阻挡、车灯夜里亮。
- **天气与时间**：晴/雨/雾/雪四套（雾浓度、光照、天空色、粒子、炊烟浓度一起变）；一天 24 小时连续过渡，日出日落、窗户和路灯逐间亮起。

## 运镜

`运镜脚本.md` 是完整的 60 秒镜头表（10 个镜头、焦段、意图、声音、字幕）。同一套机位做进了代码：`js/life.js` 的 `VW.CINE.keys`，按 C 就能在页面里看这 60 秒怎么走（不渲染视频）。

## 文件

```
index.html        页面 + HUD + 触屏控件
three.min.js      three.js r152（本地，无 CDN）
js/world.js       地形/河/桥/道路/房屋/森林/风车/碰撞
js/life.js        时间、居民日程、汽车、玩家、运镜关键帧
js/main.js        渲染、光照天气、输入、HUD、调试接口
运镜脚本.md        60 秒运镜脚本
layout.json       导出的地形/房屋数据（体检用）
townmap.png       俯视地形图（布局核对用）
```

## 调参入口

- 天气参数：`js/main.js` → `WEATHER`
- 天空/日照曲线：`js/main.js` → `skyColor()`、`applyWeather()`
- 一圈时长：`js/life.js` → `VW.Life.timeScale`（默认 1 秒 = 1/18 小时）
- 居民行为：`js/life.js` → `think()` 里各条候选的权重（吃饭阈值、躲雨门槛、酒馆吸引力、串门条件都在这一段）；`shift`/`meal` 是每人的作息种子
- 房屋位置/名字：`js/world.js` → `housesCfg`
- 运镜：`js/life.js` → `VW.CINE.keys` / `beats` / `shotLabel()`

## 已做的自检

- 12/12 房屋可从门口走到屋里（逐栋自动化实测 `inside` 命中）。
- 12 栋房屋 5×5 采样地基最低点都高于水面 0.7 米以上（不泡水、不悬空）。
- 汽车实测 3 秒内行驶 45 米、可转向、可下车，状态机正常。
- 四种天气切换生效；居民行为在 9 个时间点 × 晴/雨 下的决策矩阵逐条核过：凌晨 3:00 全体睡觉、8:30 全体上工、中午分散在各人饭点吃饭、19:30 分成 酒馆/串门/在家 三拨、23:00 全体回家睡觉；上午下雨时 6 人躲雨 6 人照常干活（按各人怕雨程度分），雨中午饭全部改到酒馆内。
- 运镜预览启动后相机按关键帧移动、FOV 变化、时间码推进。
- 页面无 JS 报错；WebGL 不可用时给出明确提示而不是白屏。
- 连续 20 游戏小时无人卡死：正常速度下 20 秒内每人位移符合其状态（干活的站着、赶路的移动 3–26 米）。

> 注：本机无头 Chromium 的软件光栅（swiftshader）跑不动这个场景，GPU 进程会崩，所以"画面像素"这一层没法在本机截图核验；几何、逻辑、布局都已用数据核验（见上）。实机观感请在手机浏览器里看。
